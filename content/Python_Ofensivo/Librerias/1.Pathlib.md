### Teoría

`pathlib` es una librería estándar de Python diseñada para trabajar con rutas y archivos de una forma mas moderna,  legible y orientada a objetos que el uso tradicional de cadenas de texto.

En lugar de manipular rutas mediante concatenación de texto, `pathlib` representa cada ruta como un objeto `Path`, permitiendo acceder a métodos específicos para consultar información del sistema de archivos, recorrer directorios,    leer archivos o construir nuevas rutas.

Una de sus principales ventajas es que abstrae las diferencias entre sistemas operativos, permitiendo escribir código mas limpio y portable.

**Objeto Path**

El punto de entrada de la librería es la clase `Path`.
A partir de ella es posible representar tanto archivos como directorios.

```python
from pathlib import path

ruta = Path.("documentos")
```

Desde ese momento la variable `ruta` deja de ser una cadena y pasa a ser un objeto con numerosos métodos disponibles.

**Construcción de rutas**

Una característica muy útil de `pathlib` es la posibilidad de unir rutas utilizando el operador `/`.

```python
ruta = Path("documentos") / "notas.txt"
```

Esto evita concatenaciones manuales y genera automáticamente la ruta correcta para el sistema operativo utilizado.

**Verificar existencias**

Antes de trabajar con un archivo o directorio es recomendable comprobar si existe.

El método `exists()` devuelve un valor booleano indicando si la ruta esta presente.

```python
ruta.exists()
```

En muchos casos resulta aun mas aún más útil utilizar métodos específicos como:

- `is_file()` -> Comprueba si la ruta corresponde a un archivo.
- `is_dir()` -> Comprueba si la ruta corresponde a un directorio.

**Lectura de archivos**

`pathlib` permite leer el contenido completo de un archivo mediante el método `read_text()`

Este método abre, lee y cierra el archivo automáticamente, evitando utilizar `with open()` cuando únicamente se necesita obtener todo el contenido.

```python
contenido = ruta.read_text(encodign="utf=8")
```

**Obtener información de un archivo**

Cada objeto `Path` dispone de atributos que permiten obtener información especifica.

Los mas utilizados son.

- `name` -> Devuelve únicamente el nombre del archivo.
- `suffix` -> Devuelve únicamente la extensión. 

**Recorrer directorios**

Para listar el contenido de un directorio existen dos métodos muy utilizados.

**iterdir()**

Recorre únicamente los elementos del directorio actual.
No entra en subdirectorios.

**rglob()**

Realiza una búsqueda recursiva, recorriendo todos los directorios y subdirectorios.
Resulta especialmente útil para localizar archivos con una determinada extensión.

---

### Práctica

```python
from pathlib import path

ruta = Path("proyecto")

print(ruta.exists()) # Verificar si existe
print(ruta.is_dir()) # Comprueba si es un directorio

for archivo in ruta.iterdir():
	print(archivo)
```

Buscar archivos recursivamente.

```python
ruta = Path("proyecto")

for archivo in ruta.rglob("*.txt")
# Puedes especificar solo por la extension necesaria
for archivo in ruta.rglob("*")
# Puedes hacer la busqueda sin ninguna preferencia
```

Leer un archivo completo.

```python
archivo = Path("usuario.txt")

contenido = archivo.read_text(encoding="utf-8")
print(contenido)
```

Obtener información de una ruta.

```python
archivo = Path("Documentos") / "archivo.txt"
archivo = Path("documentos/error.log")

print(archivo.name)
print(archivo.suffix)
```

|Método / atributo|Función|
|---|---|
|`Path()`|Crear una ruta|
|`exists()`|Verificar existencia|
|`is_file()`|Comprobar si es un archivo|
|`is_dir()`|Comprobar si es un directorio|
|`read_text()`|Leer el contenido completo|
|`iterdir()`|Recorrer un directorio|
|`rglob()`|Recorrer directorios recursivamente|
|`name`|Obtener el nombre del archivo|
|`suffix`|Obtener la extensión|
